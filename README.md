# TG Exterminatus Bot — Rotation Edition

Административный Telegram-бот на **aiogram 3** + **Telethon** (MTProto) +
**PostgreSQL**. Отслеживает участников супергруппы и по команде выполняет
массовую "зачистку" чата: банит всех известных боту пользователей (кроме
администраторов), удаляет форумные ветки (кроме текущей и General) и
создаёт заменяющие.

## Чем это отличается от обычного шаблона

Оригинальный шаблон использует **один** `BOT_TOKEN`. На практике
Telegram выбрасывает (или режет права) конкретный бот-аккаунт после
определённого порога банов подряд в одном чате — эмпирически это
происходит около **70-80 банов**. Этот порог привязан именно к аккаунту
бота, а не к тому, как написан код вокруг него — поэтому ни батчинг, ни
троттлинг, ни красивая обработка ошибок сами по себе проблему не решают.

**Новый принцип работы:** вместо одного бота — **пул из 3-4 токенов**
(`BOT_TOKENS` в `.env`). Как только активный бот получает сигнал "меня
выкинули/лишили прав" (не обычная ошибка бана одного юзера, а именно
потеря дееспособности в чате целиком) — userbot-аккаунт (тот же Telethon,
что уже используется для веток) **на лету** выдаёт права следующему боту
из пула, и операция продолжается с того же места, без вмешательства
человека.

```
Бот №1 банит 1..74  →  Telegram его выкидывает
                     →  userbot промоутит Бота №2
Бот №2 банит 75..148 →  Telegram его выкидывает
                     →  userbot промоутит Бота №3
Бот №3 банит 149..200 → всё, список кончился
```

Один и тот же `BOT_TOKENS[0]` ("primary") всегда остаётся тем, кто
принимает команды, ведёт трекинг и редактирует статус-сообщение — это
не меняется при ротации, меняется только то, КТО конкретно сейчас
вызывает `ban_chat_member` / `delete_forum_topic`.

## Функционал

| Команда | Что делает |
|---|---|
| `/fire_exterminatus` | показывает предупреждение и просит подтверждение |
| `/fire_exterminatus confirm` | банит всех известных боту пользователей, удаляет/создаёт форумные ветки, **с автоматической ротацией ботов пула при превышении лимита** |
| `/stats` | реальное число участников (по Telegram) и число отслеженных в БД |
| `/sync` | принудительно подтягивает полный список участников через Telethon |
| `/pool` | **новое** — показывает состояние пула: кто активен, кто уже сожжён |
| `/laststatus` | **новое** — показывает результат последней операции из БД (переживает рестарт процесса) |

\* Команды, как и в оригинале, не проверяют права — считается, что бот
стоит только в приватных/контролируемых чатах.

⚠️ **`/fire_exterminatus confirm` — необратимое разрушительное действие.**
Тестируй сначала на отдельном тестовом чате.

## Архитектура

```
bot.py                  — точка входа; поднимает пул ботов, polling только у primary
config.py                — читает .env (BOT_TOKENS — список!), валидирует переменные
bot_pool.py                — НОВОЕ: класс BotPool — ротация между N ботами
mtproto.py                   — Telethon-клиент + НОВОЕ: promote_bot_admin/demote_bot
forum_topics.py                — работа с ветками; НОВОЕ: BotEjectedError для ротации
utils.py                         — роли, троттлинг; НОВОЕ: is_bot_ejected_error()
get_chat_id.py                     — utility-скрипт: ID всех групп, где есть userbot

database/
  pool.py                — пул соединений asyncpg (без изменений)
  db.py                  — seen_users + НОВОЕ: bot_burns (журнал ротаций), operations (прогресс операций)

handlers/
  tracking.py            — без изменений: логирует seen_users
  stats.py                — /stats, /sync + НОВОЕ: /pool, /laststatus
  ext.py                   — /fire_exterminatus — теперь с ротацией вместо одного бота
```

## 1. Регистрация 3-4 ботов в Telegram

Повтори для каждого:

1. [@BotFather](https://t.me/BotFather) → `/newbot` → задай имя и username
2. Сохрани токен
3. Собери все токены в одну строку через запятую для `.env`:
   `BOT_TOKENS=токен1,токен2,токен3,токен4`

Чем больше ботов в пуле — тем больше суммарный "запас хода" на один
запуск `/fire_exterminatus` (каждый даёт примерно +70-80 банов).

## 2. API_ID / API_HASH userbot-аккаунта (Telethon)

Как и раньше — [my.telegram.org](https://my.telegram.org) → **API
development tools** → **Create new application** → сохрани `api_id` и
`api_hash`.

**Важно, чего не было в оригинале:** этот userbot-аккаунт теперь должен
быть добавлен в целевой чат **полноценным администратором с правом
"Add New Admins"** (в Telegram это называется "Добавление новых
админов" / `add_admins`). Без этого права `EditAdminRequest` будет
падать с `ChatAdminRequiredError`, и ротация не сможет выдавать права
следующему боту — пул окажется бесполезен.

## 3. PostgreSQL

Без изменений от оригинала — см. [dashboard.render.com](https://dashboard.render.com),
создать Postgres, взять Connection String, при необходимости открыть
`0.0.0.0/0` в Networking.

## 4. Настройка окружения

```bash
git clone <URL_этого_репозитория>
cd tg-exterminatus-rotation
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Linux/macOS

pip install -r requirements.txt
cp .env.example .env        # Linux/macOS
copy .env.example .env      # Windows
```

Заполни `.env`:

```dotenv
BOT_TOKENS=токен1,токен2,токен3,токен4
DATABASE_URL=postgresql://user:password@host:port/dbname
TELEGRAM_API_ID=число_с_my.telegram.org
TELEGRAM_API_HASH=строка_с_my.telegram.org
MINIAPP_BASE_URL=
```

## 5. Первый запуск

```bash
python bot.py
```

Как и раньше — при первом запуске Telethon запросит интерактивный вход
(номер, код, 2FA). Делай это локально, в терминале с прямым вводом.
После успешного входа появится `telegram_session.session`.

Лог `Пул ботов готов: 4 шт. Primary=@...` + `Админ-бот запущен (режим
ротации)` — всё поднялось успешно.

## 6. Настройка чата в Telegram

1. Добавь **ВСЕХ** ботов из `BOT_TOKENS` в супергруппу (как обычных
   участников — права им будут выданы динамически при необходимости;
   добавить заранее вручную можно, но не обязательно — `promote_bot_admin`
   сам попробует инвайтнуть бота через userbot, если его ещё нет в чате)
2. Userbot-аккаунт — полноценный админ с правами минимум:
   - **Добавление новых админов** (критично — без этого нет ротации)
   - **Управление темами** (нужно userbot'у для чтения списка веток)
3. Опционально: назначь `BOT_TOKENS[0]` (primary) админом заранее
   вручную с правами "Блокировка пользователей" + "Управление темами" —
   тогда он сможет начать работу без задержки на первый `promote_bot_admin`
4. `python get_chat_id.py` — узнать ID чатов

## 7. Деплой на Render

Без изменений от оригинала — Background Worker, Build Command
`pip install -r requirements.txt`, Start Command `python bot.py`, все
переменные из `.env` в Environment (включая **весь** `BOT_TOKENS`
списком через запятую — это одна переменная). `telegram_session.session`
переносится так же, как в оригинале (см. раздел 5 там).

## 8. Частые проблемы

| Проблема | Решение |
|---|---|
| `RuntimeError: BOT_TOKENS не найден` | Не создан/не заполнен `.env`, либо запуск не из той папки |
| Ротация не срабатывает, пул "застревает" на одном боте с ошибками | Проверь `/pool` — может, userbot потерял право "Add New Admins"; лог покажет `ChatAdminRequiredError` |
| `/fire_exterminatus confirm` всё равно прерывается рано | Посмотри `/laststatus` и лог — если `status=aborted` из-за `circuit breaker`, причина НЕ в лимите на бота (это отдельная ветка логики), а в повторяющихся обычных ошибках — скорее всего сеть/БД |
| При ротации новый бот сразу тоже не может банить | Увеличь `ROTATION_SETTLE_DELAY` в `handlers/ext.py` — права Telegram иногда применяются не мгновенно |
| Остальные проблемы (БД, порт 5432, `ModuleNotFoundError`, Telethon-сессия) | См. оригинальный раздел 8 — не изменились |

## Безопасность

- `BOT_TOKENS` (все токены сразу!), `DATABASE_URL`, `TELEGRAM_API_ID/HASH`,
  `telegram_session.session` — всё это эквивалент паролей. Никогда не
  публикуй их в открытых чатах, скриншотах или публичных репозиториях.
- Утечка `TELEGRAM_API_ID/HASH` в этой схеме даже чувствительнее, чем в
  оригинале: тот же userbot теперь умеет сам назначать админов в чате —
  это больше прав, чем просто чтение списка веток.
- Если засветил что-либо — перевыпусти немедленно (`/revoke` у
  BotFather для каждого токена, пересоздание приложения на
  my.telegram.org для userbot-ключей).
